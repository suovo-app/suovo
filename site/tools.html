Reference · Suovo-MCP

Tools for support work

Browse the tools available to your connected agent. Each reference lists accepted inputs, returned fields, and what Suovo does when the tool runs.

No delivery tools are exposed. Reply Review tools create or revise local proposals for human review. They cannot authorize, send, or deliver replies.

Reading tool results

Successful calls return the declared structuredContent object. A short text summary may also be present; parse the structured object for tool data. These schemas describe success results. MCP/JSON-RPC errors use the error response and do not match a success schema.

Every output object is closed: properties listed in the schema are present, with nullable values set to null when unavailable. Arrays may be empty. All timestamps are UTC RFC 3339 strings with millisecond precision and a trailing Z.

Download the complete JSON Schema contract (draft 2020-12, inputs and structuredContent outputs for every tool).
