Security and privacy

Know what a connected client can access

Suovo-MCP is designed as an opt-in local integration. A trusted client still receives the data returned by the tools you ask it to call.

Connection boundaries

  • The endpoint is disabled until enabled in Suovo Settings.
  • It binds to 127.0.0.1 and serves Streamable HTTP at /mcp. The default port is 8477; Settings can select another port.
  • The listener runs only while Suovo is running. It is not a hosted or cloud MCP service.
  • Every request requires Authorization: Bearer …. The token is stored in the operating system credential store. Suovo can rotate it; rotation invalidates the previous token.

Loopback binding limits network exposure; it does not make a bearer secret safe to share with untrusted software running on your computer. Treat the token like a password.

Data returned by tools

Tools return the local records or metadata needed for their requested task. Thread tools can return customer conversation content. Account tools can return connection status and account metadata. Queue tools can return proposed reply content and redacted thread context. Connect only a client you trust with that information.

Suovo-MCP does not promise that all related processing stays on the computer. generate_draft uses the LLM provider configured in Suovo, and list_models may query that provider. Provider and account connections have their own data handling. Consult the relevant provider terms and Suovo privacy information.

Human review and delivery

MCP can create or revise a proposal in the shared local Reply Review Queue. These are persistent local changes. MCP has no tool for approving, authorizing, sending, delivering, or retrying replies. Any delivery flow is controlled separately in the Suovo app and requires its own review and approval.

Protect the token

  • Use only clients and extensions you trust.
  • Avoid putting the token in prompts, shared logs, screenshots, public configuration files, or source control.
  • If it may have been exposed, rotate it in Suovo Settings and update the client configuration with the new value.
  • Disable the endpoint when you do not need the integration.
