Compatibility

Three versions, three purposes

Keep the Suovo-MCP API version separate from both the desktop release and the upstream MCP protocol.

VersionWhat it identifiesCurrent documentation
Suovo desktopThe installed application build.See the version and notes on each release entry.
Upstream MCPProtocol and transport behavior implemented by the client/server libraries.Suovo-MCP currently uses Streamable HTTP.
Suovo-MCP APISuovo-owned tool names, inputs, effects, and typed result contracts.Current API version: 1.0.0.

Unified result format

All 13 tools return a typed v1 object in structuredContent. Optional text content is a brief human-readable summary. Clients should parse structuredContent for tool data.

Tool names, required inputs, effects, and the typed result shapes are compatibility-sensitive. Optional input and result additions may be made without changing the major API version when existing clients remain valid. A change to a tool’s effect or data exposure requires particular care and clear release notes.

Client compatibility

A client needs Streamable HTTP support and a way to set the bearer authorization header. The endpoint address and token are shown in Suovo Settings. This documentation does not certify a specific third-party client or desktop version; check current Suovo release notes and the client’s own documentation for supported configuration details.
