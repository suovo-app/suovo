Setup

Connect a local MCP client

Suovo-MCP runs alongside Suovo on your computer. If you use Codex or Claude Code, setup takes a few clicks. The manual details are here for other clients.

Codex or Claude Code

  1. Open Suovo Settings and enable MCP. The endpoint runs while Suovo is open.
  2. Select Install or Update next to Codex or Claude Code. Suovo finds the usual configuration file and updates it after you approve the change. You do not need to copy a token yourself.
  3. Restart the client. It will find Suovo-MCP’s tools when Suovo is running.

Another MCP client

Use this route if your client does not have a built-in setup option. It needs Streamable HTTP support and a way to send a bearer authorization header.

  1. Copy the endpoint and bearer token from Settings. Treat the token like a password. Do not put it in a shared prompt, source control, or a client you do not trust.
  2. Add the connection in your client. This example shows the two values it needs. Replace the placeholder with the current token from Suovo Settings; it is not a ready-to-paste configuration for every client.
{
  "url": "http://127.0.0.1:8477/mcp",
  "headers": { "Authorization": "Bearer REPLACE_WITH_TOKEN_FROM_SUOVO_SETTINGS" }
}

Use the port shown in Settings if you changed it from the default 8477.

Try a synthetic request

After the client initializes and lists tools, for example list a small page of unread Gmail threads:

{
  "name": "list_threads",
  "arguments": { "source": "gmail", "unread": true, "limit": 5 }
}

Then use one returned thread identifier with get_thread. These examples do not contain real customer records.

Read the result

Tool data is returned in typed structuredContent; the optional text is only a short human-readable summary. See the output contract for the result shape and compatibility details.

If it does not connect

An HTTP 401 means the token is missing or no longer current. Copy the token shown in Suovo Settings; if you rotated it, update the client with the new one. Otherwise, check that Suovo is open, MCP is enabled, the port matches Settings, and the client supports Streamable HTTP.
